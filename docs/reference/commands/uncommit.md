# rgit uncommit

Undo the last commit(s), keeping the changes staged (default 1)

## Usage

```sh
rgit uncommit [OPTIONS] [N]
```

## Examples

```sh
rgit uncommit
rgit uncommit 2
```

## Arguments

| Argument | Description |
| --- | --- |
| `[N]` | How many commits to undo |

See the [global options](global-options.md) that every command accepts.
