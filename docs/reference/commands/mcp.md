# rgit mcp

Run the Model Context Protocol server over stdio

## Usage

```sh
rgit mcp [OPTIONS]
```

## Examples

```sh
rgit mcp
```

## Options

| Option | Value | Description |
| --- | --- | --- |
| `--core` |  | List only the ten core tools (status, diff, log, show, stage, unstage, commit, smartlog, undo, grep); what Codex and OpenCode install, for harnesses that load every tool into the prompt |

See the [global options](global-options.md) that every command accepts.
