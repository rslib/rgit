# rgit completion

Print a shell completion script for rgit's commands and flags

## Usage

```sh
rgit completion [OPTIONS] <SHELL>
```

## Examples

```sh
rgit completion zsh > ~/.zfunc/_rgit
rgit completion bash
```

## Arguments

| Argument | Description |
| --- | --- |
| `<SHELL>` | The shell: bash, zsh, fish, elvish or powershell |

See the [global options](global-options.md) that every command accepts.
