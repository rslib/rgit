# rgit update-server-info

Write info/refs and objects/info/packs for dumb transports, like `git update-server-info`

## Usage

```sh
rgit update-server-info [OPTIONS]
```

## Examples

```sh
rgit update-server-info
```

## Options

| Option | Value | Description |
| --- | --- | --- |
| `-f, --force` |  | Rewrite the files even when they look current |

See the [global options](global-options.md) that every command accepts.
