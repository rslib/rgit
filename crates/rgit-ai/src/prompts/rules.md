Write the message in the Conventional Commits format:

<type>[(scope)][!]: <description>

- Types: feat, fix, perf, refactor, docs, test, build, ci, style, chore, revert.
- Write the description in the imperative mood, in lowercase, with no trailing period.
- Keep the subject at most 72 characters. Use 50 if you can.
- Add `!` after the type or scope for a breaking change.
- Add a body only when it says why, or states a constraint the diff cannot show. Wrap it at 72 characters.
- Do not add AI attribution, co-author trailers or tool banners.
